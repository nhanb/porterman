Porterman is a WIP HTTP client with a GUI. It's yet another experiment in using SQLite as serializable in-memory application state. Its architectural design is similar to [webmaker2000](https://github.com/nhanb/webmaker2000), but with a few simplifications that I'll (hopefully) implement and elaborate later.
